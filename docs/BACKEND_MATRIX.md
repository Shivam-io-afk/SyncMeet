## 2. Gap Analysis & Architecture Deficiencies

### A. Missing Rejoin State Endpoint (P0)

- **Status**: No `GET /api/rooms/:roomId/state` endpoint currently exists in `server/routes/roomRoutes.js`.
- **Impact**: When a user reloads the browser, the client has to rely on stale `sessionStorage` and cannot rehydrate active participants, lock status, or breakout assignments before reconnecting the socket.
- **Remedy**: Create `GET /api/rooms/:roomId/state` guarded by `requireRoomAccess`. Return `{ room, participants, isLocked, activeBreakout, role }`.

### B. Immediate Disconnect Drop without Grace Period (P0)

- **Status**: In `server/socket/socketHandler.js` (lines 936–946), `socket.on('disconnect')` immediately deletes `socket.id` from `rooms` and broadcasts `user-left` to all other participants.
- **Impact**: On browser refresh or transient network blip, the user immediately disappears from the host's screen and their own screen. When they reconnect, they appear as a new user with a new socket ID.
- **Remedy**: Implement a 20-second grace period timer on disconnect. Mark user as `reconnecting`. Cancel the timer and update the socket ID if the user reconnects within the window.

### C. Participant Keying by `socketId` instead of Stable `userId` (P1)

- **Status**: `rooms` Map in `socketHandler.js` keys participants by `socket.id`. In `MeetingAttendance.js`, the unique index is `{ roomId: 1, userId: 1, socketId: 1 }`.
- **Impact**: Every reload changes `socket.id`, generating duplicate attendance rows and preventing the server from recognizing that the reconnecting socket is the same user.
- **Remedy**: Key `rooms` internal map or lookup by `userId`. Update `MeetingAttendance` index to `{ roomId: 1, userId: 1 }` with `leftAt: null` so rejoins update the existing record.

### D. In-Memory Notes Cache Desync (P2)

- **Status**: In `server/routes/meetingFeatureRoutes.js` (line 23), `const roomNotes = new Map();` holds AI notes in memory when DB is disconnected, but doesn't reconcile with `AINote` model upon reconnect.
- **Remedy**: Ensure write-through to `AINote` collection whenever MongoDB is connected.
